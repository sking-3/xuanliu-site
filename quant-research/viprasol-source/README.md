## How to use a script

1. Open the `.pine` file here and copy all of it.
2. In TradingView, open the **Pine Editor**, paste, and click **Add to chart**.

You can also add any of them straight from the
[Viprasol profile on TradingView](https://www.tradingview.com/u/viprasol/), which always has the
latest published version.
