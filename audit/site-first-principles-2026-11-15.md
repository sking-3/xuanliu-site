# 网站第一性原理审计 · 2026-11-15

## 必须成立的闭环

1. 页面只能展示有来源、时间、口径和权限证据的数据。
2. 选股计算必须区分长线、中线、短线，不能把不同时间尺度合并成一个胜率。
3. 实时行情必须是只读、明确延迟、明确覆盖范围，不能把快照冒充分钟基线。
4. API 密钥只能进入本机或私人管理入口，公开站不应提供凭证表单。
5. 失败、缺失、过期和未配置必须可见，不能用零值、占位价格或空列表制造“正常”。
6. 发布后的静态资源必须与当前源码、缓存版本和审计规则一致。

## 本轮修复

- 美股页补回旧行情区缺失的 `market-feed-status.js`，第三方组件失败时可以进入恢复状态。
- 修复移动端 TradingView iframe 卡在“正在连接来源…”的问题；只有真实 `load` 事件才进入成功状态，超时会收起空白区域。
- 主页、A股页、美股页统一加载长中短周期工作台版本；显式 `row.horizon` 优先，旧快照继续按策略映射。
- 图表白名单补齐加密观察品种，并更新 `chart.js` 缓存版本；动态 A 股代码继续按交易所格式校验。
- 公开美股盘中页移除旧 Alpaca Key／Secret 表单、旧 IEX 控制和无效按钮，只保留本机富途、长桥、老虎只读接入。
- 静态审计收窄到真正的 TradingView 嵌入区，补齐隐藏署名和动态图表链接检查。
- 主页、研究工作台和美股本机报价页的状态文案改为按“已连接／未连接／待验收”区分；不再把未连接的三平台写成已接入，也不把公司研究写成纯外观预览。
- 五代理页面明确当前部署只运行本机规则；AI 仅保留私有适配器接口，不读取或保存密钥。移动端补齐表单名称、焦点样式、系统色和结果状态播报。
- 公开页完成重复 ID、未标注表单控件、失效本地链接和缓存版本一致性检查；移动端行情和美股筛选器均有超时后的来源／重试回退。

## 仍未完成的能力

- `research-data/snapshot.json` 仍是 `not_configured`，没有真实的全市场 A 股或美股候选批次。
- A 股 14:00 预选仍等待合法盘中数据源验收；没有启用新排程。
- 美股财报事件当前只直接核验 NVIDIA 官方 RSS，不代表全市场事件源。
- 长线财务估值、中线行业数据和真实三家券商报价仍需本人账号权限与小批验收。
- 实盘、订单、杠杆和跟单执行保持关闭。
