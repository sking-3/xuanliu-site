# 美股板块与估值研究方案

日期：2026-11-15。状态：提案，未部署算法，未启用采集或新排程，未连接交易执行。

可以在实时额度有限时寻找值得研究的板块与股票：先用合法取得的低频证券目录、日终行情和财报缩小范围，再把实时名额留给重点候选。实时行情不必覆盖全市场；有限实时自选也不能被称为全市场扫描。

当前公开生产文件 `research-data/snapshot.json` 的美股数据仍为空；公司财务、行业分类、全市场日终批次尚未完成接入。现有三平台模块提供只读报价适配，不代表本方案已经运行，也没有据此生成真实“严重低估”名单。

## 数据与额度分层

1. **证券池与行业表**：记录当日上市状态、证券类型、交易所、代码变更、退市与行业分类版本。SEC 的 CIK 映射不等于完整可交易普通股目录；SIC 可作粗分类，细分业务和可比公司仍须按公告、收入构成核验。软件、半导体、硬件、支付等分组分别比较，不能把所有科技股混成一组。
2. **低频研究层**：依法取得完整日终行情，按实际交易日增量更新；财报只在新申报或修订后更新。价格许可、公开展示许可与 API 可访问性分别核查。缓存与批量接口用于降低负载，不通过多账号、代理或轮换入口绕过限制。
3. **实时观察层**：只有进入优先队列的股票占用实时名额；成交量口径、延迟、时间戳和市场覆盖随报价显示。快照没有同源历史分钟基线时，不生成“异常放量”或“机构资金流”结论。

SEC 的公开 submissions/XBRL API 不要求 API Key，提供公司财务数据及夜间批量档案；`data.sec.gov` 不支持浏览器跨域读取。因此应由手动运行的本机采集器下载、校验、缓存，GitHub Pages 读取经许可的处理结果；不是在网页中直接跨域抓取全市场。XBRL 标准标签不能覆盖所有公司自定义披露，缺项需回到原文。[SEC API 与批量数据说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

采集需声明工具与联系人的 User-Agent，并遵守公平访问规则。SEC 当前公布上限为每秒10次，本方案拟采用更低的串行节奏并优先增量/批量方式；403、429或权限拒绝后停止对应来源，保留原因，不改入口重试。[SEC 公平访问规则](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)

API 的限制可能分别是调用频率、同时订阅数、数据类型、历史 K 线证券数或行情权限，不能统称“账号数量”。富途文档区分这些限制，且 API 与 App 权限不完全相同；同一股票订阅不同数据类型可能分别占额度。本站目前的30只上限是应用限制，不能当成供应商配额。[富途权限与额度](https://openapi.futunn.com/futu-api-doc/intro/authority.html)

## 板块潜力：先观察基本面与价格是否相互支持

以下数值均为第一版待验证研究参数，不是已证优势，不输出上涨概率。

| 维度 | 拟用初值与证据 |
| --- | --- |
| 板块动量 | 细分行业20日、60日相对广泛市场基准收益均为正；至少60%有效成员高于50日均线 |
| 成员与流动性 | 至少10只有效成员；个股20日平均成交额至少1000万美元；缺少完整成员表则只称观察样本 |
| 基本面扩散 | 至少60%有有效财报的成员最近季度收入同比增长为正，行业收入同比中位数至少10% |
| 分散与集中度 | 同时报等权与市值权重结果、样本数、覆盖率；剔除最大成员后再核对，不让单只龙头代表整个板块 |
| 催化 | 只记录已公开的财报、指引、订单或政策原文及时间；预告不当作实际业绩 |

板块强而估值高，可归为趋势观察；板块弱但估值低，归为逆向研究。两者分列，不能通过单一总分把风险抵消掉。仅有价格上涨不能推断机构净买入。

## 盈利科技公司：用经营质量约束“便宜”

先比较同业务模式、增长和利润率相近的企业，再看自身历史区间。初版要求至少8家合格可比公司；不足时标记可比证据不足，不计算折价排名。

企业价值拟按以下口径计算，并逐项保留来源与日期：

`EV = 股权市值 + 有息债务 + 优先权益 + 少数股东权益 + 需纳入口径的租赁负债 − 可自由支配现金 − 经核验的非经营性投资`

股权市值使用同一价格时点与可核验的股数，另列期权、限制性股票、可转债的潜在稀释；不能把每股收益的期间加权平均股数直接当成当前股数。受限现金不直接抵扣。租赁是否纳入须与利润、现金流及同行口径一致，禁止重复计算。

拟同时观察 **EV／正常化无杠杆自由现金流** 和 **EV／正常化 EBIT**。EV 对应全体资本提供者；不得把未经调整的 `经营现金流−资本开支` 直接作为无杠杆口径。初始正常化参考为 `EBIT×(1−正常税率)+折旧摊销−资本开支−营运资金增加`，再逐项核对公司现金流分类、利息、税款、租赁及并购。一次性税收优惠或延迟支付不能当作持续盈利。

股份支付不是免费资金：保留其经营成本与未来稀释的影响，并做压力测试；如果已经从现金流扣除相应成本，不在股权价值上重复扣同一项。周期行业使用跨周期利润/资本开支情景，避免把景气顶点低倍数误判成低估。

拟进入“估值复核”的初值：最近TTM EBIT与正常化无杠杆现金流均为正；收入同比至少5%；毛利率同比下降不超过3个百分点；净债务／EBITDA不超过2倍；两个估值倍数相对合格同行中位数折价至少25%。这些门槛独立列明，缺数据或口径不一致时待核，不以零填充。

价值陷阱单独阻断：连续收入下滑、客户或产品集中、应收/库存快于收入增长、现金流依赖营运资金释放、债务到期压力、审计/持续经营疑虑、重述及明显稀释。低倍数本身不能证明便宜；同行也可能整体高估。

## 亏损科技公司：独立观察，不标低估买入

亏损公司不用负值或无意义的市盈率、EV／EBIT排名。EV／收入只作同业务、相近毛利率与增长的背景比较，不能单凭收入倍数判“便宜”。拟观察收入同比至少20%、毛利率不显著恶化、经营亏损或现金消耗改善、估算现金跑道至少24个月，并披露最近一年股数稀释；年稀释超过5%作为复核标记。现金跑道受融资、债务和经营变化影响，不是保证。

该组独立列为“高不确定性成长观察”，不得与盈利公司的折价分数合并，亦不输出未经证实的盈利转折或目标价。

## 估值范围与实时关注队列

每个完成复核的标的保留悲观、基准、乐观三种收入增长、利润率、资本开支、稀释与终值假设。可用可比倍数和现金流折现交叉检查，但只能得到假设下的区间；缺少可靠预测时不输出精确内在价值。初始安全边际可研究基准区间下沿的20%—35%折让，另列悲观情景损失及假设改变后是否仍成立，不宣传确定收益。

估值研究以未来数季至数年为尺度；次日方向、盘中触发与模拟成交另账。长期低估不保证次日上涨，强势突破也不等于估值便宜。

实时队列先通过证据完整性和风险检查，再按本人自选、临近正式事件、估值折价与经营质量、板块共振和数据新鲜度分别排序，保留入选/移除理由。拟以30个股票级观察位作示例：4个市场/板块代理、16个候选、10个本人自选；去重后空位可补候选。这只是配置草案，尚未自动运行。代理工具须另核行情权限，不能假设股票与指数同权。

实际容量不得超过本站30只限制及本人经核验的剩余权限；订阅数据类型数量、其他页面已占用额度和调用频率须另行计量。可用名额少于30时先减少候选与代理，优先保留本人关注；不能用新账号或快速轮换绕过订阅/历史额度。换入股票需具备同源历史基线，不能立即给出分钟异动判断。

## 时间证据、验证和启用边界

- 每条财务事实保存期间、币种、单位、表单、accession、`filed`、原文地址及首次取得时间。仅有申报日期时不能假设当天盘前已经可见；日内筛选须有足够公开时间证据，否则从保守的后续时点使用。
- 每批固定截止时间，要求事实公开证据、首次发现时间及报价 `asOf` 不晚于截止，来源接收时间另列。TTM须核对累计/单季期间并避免重复相加；后续重述不能覆盖历史版本来回填旧信号。
- 历史验证使用当时在市目录、行业归属和当时公开资料，保留退市、改名、失败及缺失样本；不能用今天的幸存公司回测过去全市场。
- 前瞻冻结候选及理由，分别核对长期相对收益、最大回撤、假设兑现和次日方向/触发；对照同板块同规模样本，计入实际可成交性、成本和数据覆盖，不挑成功案例。
- 下一步应先完成手动小批真实采集、字段/口径对账与账号权限验收，再开发全量增量处理及队列。当前未新增采集排程；未来启用前仍需本人确认。只做研究与模拟，实盘保持关闭。
