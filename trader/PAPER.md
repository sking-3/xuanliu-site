# 本机模拟跟单 v1

入口：广场账户详情 → 模拟跟单。支持熬鹰资本的已批准公开操作来源与 Hyperliquid 公开地址。其他币安账户未接入同一信号链路时不提供此入口。

## 使用

1. 建立模拟账户，默认初始虚拟资金 10,000 USDC，每次增仓固定 100 USDC。所有数值都是可调整的模拟假设。
2. 来源健康且新鲜时可以开始。启动前已有的全部记录只建立基线，绝不当新单成交。
3. 可见页面每 30 秒检查来源；当前共享公开记录读取器最多每分钟读一次远端检查点，Hyperliquid 成交缓存也为一分钟。Python 上游目标 5 秒循环不等于浏览器五秒成交、平台五秒发布或 GitHub 五秒送达。
4. 隐藏、关闭、离开页面，或来源中断/过期后暂停；重启建立新基线，不补执行缺口期间旧单。若来源检查点已停止，页面阻止开始并显示原因。最新样本试算仍可解释历史动作在当前真实盘口上的数量计算，不写入账本。
5. 导出 JSON 可保留完整账本；导入先验证资金、持仓、费用、盈亏及事件身份，再替换本机账本。导入后暂停。清理浏览器数据会丢失未导出的账本。

## 试算与来源状态

“试算最新样本”选取可确认方向的真实历史增仓动作，并用当前 Hyperliquid L2 盘口与当前模拟参数计算数量；界面分别显示历史动作时间和盘口时间。试算不新增模拟账户、不写入账本，也不代表该历史时刻能以当前价格成交。盘口或精度不满足条件时显示跳过原因。

熬鹰上游公开操作监控因分页未推进而停止时，历史样本仍可用于上述试算，“开始模拟”保持禁用。恢复上游后台采集需要单独的明确许可；建立本机账户、试算或发布静态网站均不会自动恢复采集。来源实际状态以页面的检查点与原因提示为准。

## 计算

- 固定名义：每次增仓以固定金额和当前盘口计算数量；减仓按启动后已跟随来源片段的比例，最多减掉已有模拟仓位。它不是来源完整账户仓位。
- 权益等比：来源数量 × 比例 ×（固定模拟本金或当前模拟权益）÷ 来源权益。熬鹰缺少可信来源权益；用户明确填写的权益假设只作为模拟参数，不能冒充官方数据。
- 数量倍率：来源数量 × 比例。
- 完整仓位对齐：只接受已校验完整仓位变化的来源，目标数量与已有模拟数量之差形成意图；熬鹰当前禁用。
- Hyperliquid 官方 meta 提供数量小数位与杠杆上限，l2Book 提供当前价格/数量深度；精度向下量化，检查最小 10 USDC 名义金额、保证金、总敞口与最大滑点。默认不补足最小额；补足必须主动选择。不同源合约没有准确同名市场时跳过。
- 滑点范围内逐层估算成交，允许部分模拟成交，同一轮信号不重复消耗同一份可见盘口。来源历史成交价不冒充当前可成交价。
- 重复、多版本或异常时间信号不产生重复模拟成交。来源事件、首次发现、模拟决策、盘口时间、数量、费用假设和跳过原因保留在每条记录中。

## 范围

账户仅在此浏览器 localStorage（books.paper-copy.v1），跨标签用 Web Locks 互斥与 revision 检查。来源与盘口只读公开数据；请求不携带交易凭据。代码没有签名、钱包、交易账户 API、交易权限、交易所下单动作或后台模拟执行。GitHub Pages 关闭后不会继续模拟。

模拟市场为 Hyperliquid 默认永续 DEX，计价 USDC。手续费为手动假设；未模拟资金费、强平、挂单排队或真实订单延迟。USDT 来源的权益假设按 USDC 1:1 模拟，未模拟汇率。缺少新鲜报价时权益留空。结果不是完整实盘收益或盈利承诺。

本地核验导出账本：`node tools/paper_copy/check.cjs <export.json>`。该命令不联网。自动测试使用仅存在于 audit/ 的合成事件和盘口，不发布为真实行情或模拟业绩。
