## 数据范围

scripts/collect_binance.cjs 独立编写，只使用匿名公开网页数据接口，不使用 Apify、币安密钥、Cookie 或登录。每个账号先核对精确组合 ID、ACTIVE 状态与 positionShow，再请求仓位、最近七天订单第一页和历史仓位第一页。每种历史最多20条，始终标记 complete:false；近七天查询窗口可能返回较早下单但近期更新的订单，页面保留这些真实返回记录并显示两种时间。订单样本不是逐笔成交或完整交割单，也不能补出手续费、资金费或完整账户收益。

仓位按非零数量过滤并保留十进制字符串；BOTH仓位按原数量符号区分多空。首次成功或长时间中断后建立基线，连续两次未见原仓位才记录“观察到归零”，不把快照差异当作已核实成交。每个账号独立保留24份快照、200条观察；采集时间不等于来源更新时刻，超过30分钟自动标旧。

## 停止与缺失

- 身份不符、结构变化、非公开仓位等使该账号持久停止。隐藏会清除新发布文件中该账号的历史数据；已经存在的仓库历史不会因此撤回。
- HTTP 202/401/403/418/429/451 或非成功业务码使整批持久停止，后续账号不再请求。下次定时运行保留停止状态，不自动解除。
- 所有请求顺序执行，间隔至少2秒，单次15秒、响应2MB上限，无同轮自动重试。不得通过代理、凭据替换或重跑绕过停止。
- 保留现有前次 workflow 完整成功检查。若前次采集后的提交/发布未确认成功，或重跑同次任务，则不请求来源。
- 本次试查的 chartgol 历史数据出现 schema_changed，未加入采集名单，不重试；一亏三千里、青木问道、广西数学哥及 akato 的详情未向匿名查询开放仓位，未请求其仓位/历史。熬鹰资本此前未开放仓位，也未加入本次名单。

## 发布与兼容

portfolios.json 包含三个独立单账号 feed；页面只读取这个同源文件。snapshot.json 保留原账号兼容入口。旧版任务若在并发期间写入了更新的原账号快照，首次新任务会保留该状态；任一既有停止标记不会被较新的正常快照清掉。新账号初始状态为空，不放置模拟交易，首次有效数据由部署任务实际取得。

沿用现有 Pages 工作流与每小时27、57分钟的计划。GitHub调度和前序 Hyperliquid 任务会影响实际发布时间，是否刷新成功以各账号时间和 Actions 记录为准。浏览器每5分钟检查本站文件并在隐藏时暂停，不会直接访问币安。
