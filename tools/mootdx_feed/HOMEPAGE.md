# A 股短线龙头观察：首页状态与后续接入

首页相邻第二位置改为“A 股短线龙头观察”。它与既有市场异动、沪市官方异动组件分开。
当前为静态“待核验”状态：关键证据尚未齐备，暂不展示候选。没有股票排名、价格、
默认龙头、虚构候选或假数据日期；也没有新增采集、数据请求或自动化任务。

页面展示四类未来候选所需证据：
- 连板高度：连续涨停天数、所属市场与交易日期。
- 热点板块：题材来源、板块联动与辨识度。
- 成交与换手：成交额、换手率及近期对比。
- 风险提示：风险标识、停复牌及异常波动公告。

涨停记录与龙头判断必须分开。涨停只提供观察线索；单日涨幅、涨停次数或成交额
不能独立确认龙头。后续呈现的是附日期和依据的观察候选，不把涨幅前三或旧成交额
名单改名成龙头，也不预设必然存在一个全市场龙头。

## 当前实现

index.html 的 #home-short-leaders 紧随 #home-tv-movers；#market-radar 及原有
沪市异动组件不改动。四类证据是说明字段，不是已取得的数据。
首页不再加载 home-active-stocks.js，也不请求 research-data/a-active-stocks.json。
旧五日成交额模块及其单元测试作为未启用的独立代码保留；其生产 JSON 仍为空，
原有发布字节与日期校验也保留。旧格式不能作为未来龙头候选输入。

## 后续生产者必须先提供的证据

后续数据接入需单独设计和复核；本次没有宣称数据源可用或授权已解决：
1. 明确证券范围、完整交易日、数据日期和适用的证券规则；连续涨停链必须逐日可核验，
   不用缺失补零，不把盘中触板与最终封板混同。来源不足时连板高度保持未知。
2. 题材归属附来源和时间，并提供同板块联动证据；主观题材标签或名称相似不独立成立。
3. 成交额、换手率和比较窗口须有单位、口径及缺失标记，不用成交量或价格涨幅替代。
4. 风险字段逐项区分已核验、已提示和未知；停复牌、风险标识及异常波动公告须可追溯。
5. 每个候选附 dataAsOf、证据来源/时间、入选依据与缺失项；任何关键证据不足，不进入
   已核验候选展示。报告覆盖范围，避免把有限样本称为全市场。
6. 未来快照使用独立版本化合同、持久撤回与防回滚机制，不能复用五日成交额 ready
   标志。来源守卫、旧停止状态与允许使用/展示范围由独立接入变更解决。

PR #43 的真实采集仍关闭，本次不配置权威状态服务、不迁移或修改旧停止记录。
TradingView 仅用于已有的行情组件与后续候选的查看入口，不提供龙头证据生产者。

## 验证

audit/leader-observation-browser.cjs 验证实际首页在 Chromium/WebKit 的
1440/768/390/375 宽度：待核验状态、四类证据、没有伪造候选、没有旧成交额读取、
页面恢复/刷新仍不恢复旧名单，以及原异动组件的路由未破坏。外部 HTTP/WebSocket
全部被测试拦截，导航使用明确的合成组件，不能作为真实行情或龙头数据验收。
