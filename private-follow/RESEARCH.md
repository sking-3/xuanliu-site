# 私人股票行情接入

入口 `/research` 复用原 Sites 所有者身份和服务端密钥保险库。没有创建新账号体系或扩大访问名单，没有后台排程，也没有交易、撤单或资金操作路由。

当前版本已实现两个供应商的固定只读请求、分页处理、收盘批次组装、自选分钟观察和异动计算。**尚未录入或验证用户真实行情凭证，尚未取得真实完整市场批次。离线测试和界面检查不等于真实行情已跑通。**

## 用户操作

1. 注册 Tushare Pro 和 Alpaca 免费账号，Alpaca 可选 Paper Only，不需入金。
2. 在私人页的“行情来源”录入 Tushare Token 或 Alpaca Key/Secret，确认账号许可本人研究使用。凭证只提交到本站的所有者服务端，以原 AES-GCM 保险库加密；浏览器持久存储、公开 GitHub 和日志均不保存凭证。
3. Alpaca 默认 IEX 单交易所。只有实际获得相应历史数据权限时才选择 SIP 延迟模式；Paper Only 与 SIP 权限的官方说明并不完全一致，必须以账号授权和实际成功结果核验，不能默认具有权限。
4. 先运行一次对应市场收盘批次。首次会获取61个交易日，可能需要数分钟；成功来源响应可缓存，失败保留已有结果。目录截断、重复、缺行情、资格或复权不足时保留待核，不伪造候选。
5. 在“盘中自选”添加代码，然后点击启动本页监控。每个市场最多30个自选；约每60秒读取，页面隐藏/关闭停止，休市时显示实际历史时间。异动雷达只覆盖这些自选，**没有声称免费全市场实时扫描**。

## 费用和覆盖依据（2026-11-13查阅官方说明）

- Tushare 注册账号与接口积分/权限不同。股票目录、交易日历、复权及涨跌停等有相应积分门槛；`stock_st` 日快照为3000积分。`rt_min` 实时分钟与 `stk_mins` 历史分钟分别需要相应权限。没有代表用户购买任何权限。
- `daily` 的手、千元换算为股、元；分钟 `vol/amount` 按股、元处理。股票复权因子相对本批末日归一化，原始来源响应保留在私人缓存。
- Alpaca Basic 提供有限范围 IEX；SIP 历史查询的结束时间至少向前16分钟留出边界，不请求免费权限范围内的最新 SIP。API请求指定 feed，不自动从被拒 feed 换来源。
- 个人数据只在受认证研究页展示，不写入公开行情 JSON。免费读取不代表拥有公开再分发权限。

## 风险资格与信号口径

A股只接受沪深主板普通股的资格核验，读取当日真实限价、ST名单和停复牌；任何缺项待核。原五种模式尚未确认完毕，读到行情不代表策略已全部实现。

美股三条研究规则独立计算再合并。IEX量能不作为全市场量能；当前目录不是历史时点目录，名称或交易状态不能确认的普通股资格待核。规则命中、正式候选和全市场覆盖分别表示，不互相替代。

异动只比较同市场时段、同分钟、至少10个历史交易日的成交额中位数，最近最多20日。量比3倍为观察，另有绝对1分钟涨跌至少1%才作量价确认；SIP延迟数据明确标“延迟异动”，不伪称即时信号或机构净流入。Alpaca分钟成交额是VWAP乘成交量的派生值。来源时间、接收时间、发现时间保留；重叠或修订的分钟记录按代码和来源时间去重。

## 存储与停止

D1沿用 `connections/source_stops`，新增迁移 `0003_research_data.sql`。大结果分为每段400000字符，由D1原子批处理保存，避免单行体积限制。成功的轻量来源响应保留最初接收时间；读缓存不刷新来源时间。原始下载和个人结果不进入源码或公开发布包。

Tushare请求预算最多约46次/分钟，Alpaca最多约120次/分钟，多个页面共享D1预约。历史分钟基线在当前页面缓存，同一天刷新不重复拉取整段基线。实际供应商限制更严时，以拒绝证据为准。

HTTP401/403/429持久停止整个对应数据供应商；权限逻辑拒绝停止对应接口。更新凭证不清除停止记录，无镜像、代理、备用域名、客户端切换或自动重试。GitHub被拒的队列与完成检查查询完全未使用。
